Sound Layer Plan for MOTION_SUPREME interactions
===============================================

1. baseDrone — persistent ambient drone that fades in when any interaction starts the audio context.
2. interactiveTextHover — triggered while hovering over the MOTION SUPREME interactive letters.
3. folderHover — fades up whenever a 3D folder is hovered in either orbit or aligned mode.
4. folderSelect — short burst when a folder becomes the active selection (click or alignment).
5. edgeScroll — engages while the cursor pressurises the left/right edges to slide through folders.
6. webPulse — activates when the MOTION333 network regenerates or jitters beneath the lineup.
7. orbitMagnet — rises when a folder is magnetised toward the cursor in orbit mode.
8. alignedState — subtle layer that persists while the lineup mode is active.
9. showcaseHover — triggered by hovering the right-hand project name panel entries in aligned mode.
10. scrollWash — a soft shimmer that responds to any mouse or trackpad scroll gestures.
11. themeToggle — momentary chord shift when the light/dark mode button is pressed.
12. scrollProgress — gentle ticking synced to the custom scrollbar fill as the page advances.
13. scrollUnlock — bloom that plays once the five-second scroll lock releases.
14. showcaseSelect — pronounced swell that triggers when a showcase entry is clicked and stretches taller than its neighbors.
15. showcaseHoldSelect — a delayed swell that fades in if an entry auto-selects after the 3s hover hold.
16. topoPulse — soft whoosh that accompanies each background topo animation burst triggered by folder selections or showcase clicks.
17. showcasePreviewAppear — airy harmonic swell that fades in as GIF preview squares rise into place when hovering project names.
18. showcasePreviewDrop — percussive falloff that triggers when preview squares lose focus and drop off the page.

Each layer is currently generated through Web Audio oscillators as placeholders. Replace with provided audio assets later by updating the SoundManager.createLayer configuration.
